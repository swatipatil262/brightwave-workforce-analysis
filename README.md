# BrightWave Workforce Analysis Using Python

## Project Overview
BrightWave Solutions is a fictional company used for this portfolio project. The project analyzes employee workforce data to understand department distribution, salary patterns, experience, demographics, location, and employee status.

## Business Questions
1. How many employees are in each department?
2. Which department has the highest average salary?
3. What is the employee experience distribution?
4. How is the workforce distributed by gender and location?
5. What percentage of employees have exited?
6. What basic workforce insights can support operational planning?

## How to Run
1. Install Python 3.
2. Open the project folder in VS Code or Jupyter Notebook.
3. Install dependencies:
   `pip install -r requirements.txt`
4. Open `notebooks/workforce_analysis.ipynb`.
5. Run the cells from top to bottom.

## Dataset
The dataset is synthetic and created specifically for this portfolio project. It does not contain real employee information.

## Outcome
The project demonstrates practical beginner-level Python data analysis and visualization skills that can be applied to workforce and business operations data.
